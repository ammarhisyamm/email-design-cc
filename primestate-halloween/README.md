Preheader (both): *A limited-time Halloween sale opens Monday. Watch your inbox.*

- Copy is verbatim from the brief, branded Prime State (primestateaus.com). No offer, code or shop button in the teaser.
- Halloween palette from the brief: #150B24 base, #FF7A1A pumpkin, #F5EFE6 bone. Headline in Creepster (image, alt = headline); body in Montserrat as live text.
- Banner, body, countdown caption, sign-off and footer are live text, so the email reads with images off.
- Countdown digits are a static placeholder — swap in the live Omnisend timer (counts down to Monday's launch).
- Footer: Prime State logo, primestatebusiness@gmail.com, policy links, research-use line, unsubscribe. No social icons (none on the site).
- All scene art (castle, gates, cellar, sign, stone arch, candy, cobwebs, bats, trust badges) is AI-generated. Candy never touches a vial; vials appear only as silhouettes.

Rebuild: edit `src/make_teasers.py`, run it, then `src/build.py` (see the main README for the slicer).
